# Responsible Vulnerability Disclosure Policy

BroML takes application security seriously and values the contributions of the cybersecurity and security research community.

## Scope
This policy applies to:
- BroML Mobile App (Android APK, iOS)
- BroML Web Application (`https://broml-app.vercel.app`)
- Cloudflare Edge Security Layer & Worker APIs
- Cloud Firestore & Cloud Storage Security Rules

## Out of Scope
- Denial of Service (DoS/DDoS) attacks against production infrastructure.
- Social engineering (phishing, vishing) targeting BroML staff.
- Physical attacks against data centers or offices.

## Reporting a Vulnerability
If you discover a security vulnerability, please submit a detailed report to **security@broml.ai** including:
1. Vulnerability description and CVSS 3.1 estimate.
2. Step-by-step reproduction instructions with safe, non-destructive test payloads.
3. Affected components, routes, or files.
4. Suggested defensive remediation or patch.

## Our Commitment
- We will acknowledge receipt of your report within 48 hours.
- We will provide an estimated timeline for validation and remediation.
- We will notify you once the vulnerability has been patched.
- We will recognize your contribution in our Security Hall of Fame (with your consent).
